# نظام النسخ الاحتياطي للفايربيز

## 📋 نظرة عامة

تم إنشاء نظام شامل للنسخ الاحتياطي لبيانات الفايربيز يتيح للمديرين إنشاء نسخ احتياطية واستعادتها بسهولة وأمان.

## 🚀 المميزات

### ✅ المميزات المنجزة
- **إنشاء نسخ احتياطية شاملة**: نسخ جميع المجموعات المهمة وملفات Storage
- **واجهة إدارة احترافية**: واجهة سهلة الاستخدام لإدارة النسخ الاحتياطية
- **استعادة البيانات**: إمكانية استعادة أي نسخة احتياطية بضغطة واحدة
- **جدولة تلقائية**: إعداد نسخ احتياطية مجدولة (يومية/أسبوعية/شهرية)
- **ضغط البيانات**: تقليل حجم النسخ الاحتياطية
- **تشفير البيانات**: حماية البيانات الحساسة
- **إحصائيات مفصلة**: عرض معلومات شاملة عن النسخ الاحتياطية

## 🔧 الاستخدام

### 1. إنشاء نسخة احتياطية

```typescript
import { BackupService } from '@/lib/services/backup-service'

// إنشاء نسخة احتياطية جديدة
const metadata = await BackupService.createBackup(
  'نسخة احتياطية يومية',
  'نسخة احتياطية تلقائية'
)
```

### 2. جلب النسخ الاحتياطية

```typescript
// جلب جميع النسخ الاحتياطية
const backups = await BackupService.getBackups()

// جلب الإحصائيات
const stats = await BackupService.getBackupStats()
```

### 3. استعادة نسخة احتياطية

```typescript
// استعادة نسخة احتياطية
await BackupService.restoreBackup('backup_id')
```

### 4. حذف نسخة احتياطية

```typescript
// حذف نسخة احتياطية
await BackupService.deleteBackup('backup_id')
```

### الجدولة التلقائية
- **يومياً**: في وقت محدد كل يوم
- **أسبوعياً**: مرة واحدة في الأسبوع
- **شهرياً**: مرة واحدة في الشهر

### إعدادات متقدمة
- تحديد وقت التشغيل
- تفعيل/إلغاء الجدولة
- تشغيل نسخة احتياطية فورية

## 🚨 تحذيرات مهمة

1. **الاستعادة**: استعادة النسخة الاحتياطية ستحل محل جميع البيانات الحالية
2. **الحجم**: النسخ الاحتياطية الكبيرة قد تستغرق وقتاً أطول
3. **الشبكة**: تأكد من اتصال إنترنت مستقر أثناء النسخ
4. **الصلاحيات**: تأكد من وجود صلاحيات كافية للوصول للفايربيز

## 🔄 دورة حياة النسخة الاحتياطية

1. **الإنشاء**: نسخ البيانات من Firestore و Storage
2. **الضغط**: تقليل حجم البيانات
3. **التشفير**: حماية البيانات الحساسة
4. **الحفظ**: حفظ في Firebase Storage
5. **التوثيق**: حفظ البيانات الوصفية في Firestore
